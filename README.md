# 생기부장인

초등 교사가 학기말 **교과학습발달상황**(항목 이름: 성취수준 및 특기사항)을 정리하는 웹 앱의 첫 버전입니다.

학급 등록부터 나이스에 붙여넣을 문장까지, 여덟 단계를 이 브라우저 안에서 진행합니다.

공개 주소: [https://jeongdon-heo.github.io/saenggibu-jangin/](https://jeongdon-heo.github.io/saenggibu-jangin/)

## 학생 정보는 이 브라우저에만

- 계정, 서버 저장소, 데이터베이스가 없습니다.
- 학급, 명단, 성취기준, 관찰 메모, 문장은 이 브라우저의 `localStorage`에만 있습니다.
- 화면을 다른 사람에게 보여 줘도 서버로 학생 정보가 전송되지 않습니다.
- 브라우저 기록을 지우거나, 시크릿 창을 닫거나, 다른 컴퓨터를 쓰면 데이터가 사라집니다.
- **백업 파일 저장**으로 JSON 파일을 받아 두고, **백업 파일 불러오기**로 되돌립니다. 백업에는 실명과 관찰 메모가 포함될 수 있으니 개인 폴더에 두세요.
- **모든 데이터 지우기**는 이 브라우저의 저장만 지웁니다.
- 실명은 필수가 아닙니다. 번호와 이니셜(별칭)만 쓰는 것을 권합니다. 엑셀에는 실명과 관찰 메모를 넣지 않습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://127.0.0.1:47321](http://127.0.0.1:47321) 을 엽니다.

```bash
npm test        # 글자 수·바이트, 백업 저장/불러오기 등
npm run build   # 정적 파일 dist/
npm run preview # 빌드 결과 확인
```

`npm run dev`는 주소 루트에서 열립니다. `npm run build`는 GitHub Pages 경로 `/saenggibu-jangin/`에 맞춰 파일을 만듭니다. 그 결과를 보려면 `npm run preview` 후 [http://127.0.0.1:47321/saenggibu-jangin/](http://127.0.0.1:47321/saenggibu-jangin/) 을 엽니다.

`main`에 푸시하면 GitHub Actions가 설치, 테스트, 빌드를 하고 `dist`를 GitHub Pages에 올립니다. 워크플로는 Pages가 꺼져 있으면 켜 보려고 하지만, Actions의 기본 토큰으로는 저장소의 Pages를 처음 만들지 못합니다. 배포가 그 단계에서 멈추면 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 고르고, Actions 탭에서 워크플로를 다시 실행하세요. 서버 프로그램과 환경 변수는 필요 없습니다. 주소는 `https`라 문장 복사가 안정적입니다. 사이트에 접속해도 학생 기록은 그 브라우저 안에만 남습니다.

## 여덟 단계

1. 진도표 순서로 학습주제를 만들고 평가요소·성취기준과 연결합니다. 공개수업·학기말 총정리 행은 건너뜁니다.
2. 교사 평가: 학습주제마다 관찰·지필·수행과 학교 수준(없으면 상·중·하)을 표시합니다.
3. 학생 자기평가 문제를 만들고 설문에 넣을 것을 고릅니다.
4. 고른 문제만 학생용 구글 폼 미리보기와 실행 스크립트로 만듭니다. 구글 계정은 저장하지 않습니다.
5. 응답을 채점한 뒤 교사 평가와 나란히 보고 수준을 확정합니다. 교사 평가를 우선하고, 다르면 표시합니다.
6. 확정한 두 방향 수준과 선생님 메모로 평어 초안을 만듭니다. 학생 답·번호·별칭·실명은 인공지능에 보내지 않습니다.
7. 평어에 관찰·지필 근거가 있으면 그 문장으로 나이스 관찰기록을 만듭니다.
8. 확인 완료된 문장만 번호 순으로 복사하거나 엑셀로 받습니다. 한 줄에 한 과목, 또는 과목을 가로 칸으로 고를 수 있습니다.

인공지능이 쓴 문장은 초안입니다. 2026 기재요령대로 선생님이 고치고 확인 완료를 누른 뒤에만 나이스 복사와 엑셀에 들어갑니다.

## 바이트 계산

2026학년도 초등 기재요령을 따릅니다.

- 한글 1자 = 3바이트
- 영문·숫자 1자 = 1바이트
- 줄바꿈(Enter) = 1바이트. 윈도우 줄바꿈도 한 번으로 셉니다.
- 공백은 기재요령에 따로 없어 **1바이트로 계산**합니다. 화면의 ‘계산 기준’에 이 가정을 적어 두었습니다.
- 영문 문장부호 등 ASCII 문자는 1바이트, 한자 등 그 외 문자는 3바이트입니다.
- 글자 수는 공백과 줄바꿈을 포함합니다.
- 2026학년도 초등 교과학습발달상황에는 고정 글자 수 제한이 없습니다. 칸이 막히지 않고 숫자만 보여 줍니다.

## 엑셀 열

번호, 이니셜, 과목, 성취수준 및 특기사항, 글자수, 바이트

## 문제 만들기

3단계에서 평가요소와 수준별 기준으로 학생 자기평가 문제를 만듭니다. 설문에 넣을 문제는 그 화면에서 고릅니다. 교사 평가는 2단계 표에 따로 남고, 학생 답은 보내지 않습니다.

인공지능에는 학년, 과목, 단원, 평가요소, 성취기준, 수준별 기준만 보냅니다. 보내기 전에 번호·별칭·실명·메모·문장이 섞였는지 확인하고, 있으면 막습니다. API 키는 화면에서 선생님이 입력합니다. 학급 백업 파일에는 넣지 않습니다. 키가 없으면 프롬프트를 복사해 ChatGPT나 Gemini에 넣고, JSON 답을 다시 붙여넣을 수 있습니다.

나이스 진도표 xlsx(순번, 학년, 학기, 편제, 단원, 학습내용, 쪽수, 보조쪽수, 해당차시, 전체차시, 준비물)를 과목 화면에서 불러올 수 있습니다.

## 구글 폼과 응답

4단계는 3단계에서 고른 문제만 폼 미리보기로 보여 주고, 선생님 구글 계정에서 실행할 Apps Script를 만듭니다. 학생에게는 번호와 문항, 보기만 갑니다. 정답, 채점 기준, 목표 수준, 구글 비밀번호는 앱에 남거나 들어가지 않습니다. 스크립트 없이 문항 텍스트만 복사할 수도 있습니다.

5단계는 구글 시트 CSV를 이 브라우저에서 읽어 번호로 명단과 연결합니다. 객관식과 단답은 자동 채점하고, 서술은 채점 기준을 보면서 선생님이 채점합니다. 같은 화면에서 교사 평가와 학생 설문 수준을 나란히 보고, 교사 평가를 우선한 제안을 확정합니다. 학생 답은 근거일 뿐 생기부 문장으로 복사하지 않습니다. 응답, 교사 평가, 확정 수준은 백업과 모든 데이터 지우기에 포함됩니다.

구글에 앱이 직접 로그인하는 방식(OAuth)은 클라우드 프로젝트와 토큰이 필요해 쓰지 않습니다. 선생님이 자기 계정에서 스크립트를 실행하는 편이 계정과 학급 기록을 섞지 않습니다.

## 배포 뒤 선생님이 할 일

1. 올린 주소를 엽니다.
2. 학급과 성취기준, 평가요소를 등록하거나 백업 파일을 불러옵니다.
3. AI를 쓰려면 설정에서 본인 키를 넣습니다. 없어도 프롬프트 복사로 진행할 수 있습니다.
4. 확인 완료한 문장만 나이스에 붙여넣습니다.
